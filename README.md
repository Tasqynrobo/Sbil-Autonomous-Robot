# Infinity Autonomous Robot

Autonomous robotics platform powered by Raspberry Pi 4 with solar-assisted docking station.

---

# Overview

Infinity Autonomous Robot is a multifunctional autonomous robotics platform designed for engineering competitions, automation research, and future AI integration.

The robot combines mobility, autonomous systems, energy management, and utility features into a single modular platform.

This project was developed using Raspberry Pi 4 as the primary computing system together with FTC REV robotics hardware for movement and control.

---

# Main Features

- Autonomous movement system
- Solar-assisted docking station
- Rechargeable power management
- Touchscreen control interface
- Raspberry Pi 4 onboard computer
- FTC REV mobility platform
- Modular robot chassis
- Internal cargo compartment (“Guardian Box”)
- Object transportation capability
- Sensor integration
- Expandable AI-ready architecture

---

# Guardian Box System

The robot contains a built-in internal storage compartment called the “Guardian Box”.

This compartment allows the robot to carry:
- small tools
- robotics components
- portable devices
- utility objects

The cargo system was designed as an additional practical functionality for future real-world robotics applications.
