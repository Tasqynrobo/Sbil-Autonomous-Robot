# Infinity Autonomous Robot

Autonomous robotic platform powered by Raspberry Pi 4 with solar-assisted docking station.

## Overview
This project is a fully functional autonomous robot designed for robotics competitions and engineering research.

The robot uses Raspberry Pi 4 as the main processing unit and FTC REV hardware for mobility and control systems.

## Features
- Autonomous movement
- Solar-assisted docking station
- Touchscreen interface
- Modular robot structure
- Sensor integration
- Rechargeable power system
